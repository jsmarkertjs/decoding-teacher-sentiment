Decoding Teacher Sentiment

A multi-task CNN that predicts Quality and Difficulty from RateMyProfessor reviews, with LIME word-level explanations.

DATA-441 Final Project American University 1D CNN + LIME
View on GitHub Live Demo Presentation Slides

Overview

RateMyProfessors scores are vague averages. A 3.5 overall rating could mean an easy grader or a great teacher -- you can't tell from the number alone.

This project builds a multi-task 1D CNN that separates those two factors, predicting both Quality and Difficulty scores from the same review text, then uses LIME to show which words drove each prediction.

Run It Yourself

1. Notebook (full reproduction)

pip install -r requirements.txt
jupyter notebook notebooks/project_final.ipynb

Scrape data, train the model, see LIME explanations. No API keys needed.

2. Streamlit Demo (quick preview)

cd demo
pip install -r requirements.txt
streamlit run app.py

Browse pre-computed LIME explanations for 10+ reviews without installing TensorFlow.

3. Modular Python

from src.preprocessing import clean_for_nn, prepare_data
from src.model import build_model
from src.lime_explainer import explain_difficulty, explain_quality

Import individual components into your own scripts.

Limitations

  • Overfitting: The model overfits after about 3 epochs. The final weights at epoch 10 trade generalization for training accuracy.
  • Data scope: Trained on American University reviews only -- may not generalize to other institutions.
  • No model weights: The model is about 4 MB. Run the notebook to train fresh weights from your data.
  • LIME regression hack: The 2D-array trick is a workaround, not a proper solution. SHAP or a native regression explainer would be cleaner.
